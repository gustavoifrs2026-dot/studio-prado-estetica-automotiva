# Studio Prado — aplicativo/site instalável

Esta é uma primeira versão completa em formato web/PWA, preparada para:
- celular e computador;
- link na bio do Instagram;
- instalação como aplicativo;
- catálogo de serviços e preços;
- galeria com as fotos fornecidas;
- agendamento enviado para o WhatsApp;
- endereço, horários e formas de pagamento.

## Publicação
Para usar como site, envie esta pasta para uma hospedagem que aceite arquivos estáticos.
Para Google Play, esta PWA pode ser empacotada como Android (TWA/Capacitor) e publicada na conta Google Play Console da empresa.
